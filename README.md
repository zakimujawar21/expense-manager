# 💰 Expense Manager

A simple and clean full-stack web application for managing daily expenses.

Expense Manager allows users to create an account, securely log in, add and manage expenses, search and filter expenses, and view their monthly spending summary.

---

## ✨ Features

- 🔐 User Registration & Login
- 🔒 Secure JWT Authentication
- 🔑 Password Hashing
- ➕ Add Expenses
- ✏️ Edit Expenses
- 🗑️ Delete Expenses
- 🔎 Search Expenses
- 🏷️ Filter Expenses by Category
- 📊 Monthly Expense Summary
- 👤 User-specific Expenses
- 🚪 Logout
- ❌ Account Deletion
- ⚠️ Form Validation & Error Messages
- 📱 Fully Responsive Design
